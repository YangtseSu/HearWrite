# 词库规范与贡献指南

内置词库随 APK 原样打包（`app/src/main/assets/`），是应用的**唯一**词表来源；一份坏行会立刻发给所有用户。本文是词表的数据契约、校验方式与贡献流程。架构与行为契约见 [`../AGENTS.md`](../AGENTS.md)，功能规划见 [`ROADMAP.md`](ROADMAP.md)。

## 1. 词库的两类内容

| 类别 | 目录 | 来源 | 维护口径 |
|---|---|---|---|
| **教材同步** | `人教版小学`、`人教版初中`、`人教版小学语文`、`人教版初中语文`、`外研版初中`、`闽教版小学`、`仁爱版初中` | 教材（识字表/写字表/词语表/单元词表） | 逐册对齐教材目录，缺册补齐；课本怎么排就怎么排 |
| **公共语料** | `中考1600`、`高考3500`、`初中2182`、`义务教育语文课程标准` | 考纲/课标等公开字词表 | 按官方字表/词表整包收录，不做教材口径改写 |

两类都禁止"顺手润色"：词库是**数据**，词条顺序即听写顺序，列内容即朗读内容。

## 2. 目录与文件名

```
app/src/main/assets/<分类目录>/<词表名>.txt
```

- 分类目录即词库里的一个分类；`dict/`、`compounds/`、`audio/` 是保留目录，不是分类。
- 词表名 = 文件名去掉 `.txt`，就是**存储键**的一部分（`default_<分类>_<词表名>`），收藏、错词来源、听写记录都指向它。
  **改名 = 孤立用户已有的收藏与错词来源**（它们降级成"未知来源"）。只增不改名。
- 列表排序由 `domain/LabelOrder.kt` 的 `compareLabels` 决定：`第X册` 按册号，其余按"年级 → 上下全"，再按中文拼音 → 笔画 → 码点，拉丁串按字母。**文件名决定显示位置**，所以按册次写全（`三上 Unit 2`），不要用 `Unit2`。

## 3. 行格式

一行一个词条，UTF-8、LF 换行、无 BOM、无空行、无行首尾空格。

```
apple | n. | 苹果          ← 英文：词头 | 词性 | 中文释义（只有词头也合法）
月 | yuè | 月亮            ← 生字：字 | 拼音（带声调） | 组词（必须含本字）
很 | hěn                   ← 生字（只有读音）：无组词时省掉第三列，不要写成空列
香蕉                       ← 词语/词组：直接一行
you're = you are           ← 展开式：只朗读等号左侧
```

- 列数为 **1、2 或 3**（全角 `｜`、半角 `|` 均可）。末列没有内容就**省略**，不要留空列（`apple | n. | ` 与 `月 | yuè | ` 都是坏行）。
- 词性列不校验词表：ECDICT 的 `n.`、课本里的 `n. & v.`、`v.aux.`、`pl, n` 都合法，朗读不会读它。
- **英文行**：词性+释义可留空，应用会用内置 ECDICT 离线补齐（`dict/ecdict-meta.json`）。ECDICT 查不到的是**词组**（`be good at`、`a bottle of`），补不出来，建议直接写全三列。
- **生字行**：拼音必须是**带声调**的拼音字母（`lǚ`，ü 写作 `ü`），不是数字调（`lv3`）——多音字筛选靠它（见 AGENTS.md 组词朗读）。组词必须含本字，否则该行朗读时会被丢弃。
- **裸汉字行**（只有字、没有拼音/组词）：合法，应用会用 `dict/hanzi-meta.json` 补常用读音与默认组词（若无组词可补，则只补读音，输出 `字 | 拼音` 两列）。拍照识词的中文结果就是这种形态（OCR 只保留汉字）。
- `dict/hanzi-meta.json` 的取值顺序：① `scripts/data/hanzi-meta-overrides.tsv` 的人工条目；② 内置词表里的 `字 | 拼音 | 组词` 行（课本注音优先）；③ 常用词表的**二字词**证据（取该字在多音候选里的常用读音，声调读音优先于轻声）；④ 该字的**单字条目**（仅当词表里没有任何含该字的词时，如 很/您/刘）。组词取"读音一致的最常用二字词"；找不到就只留读音。**不臆造读音**：两层证据都没有的字不进表，应用中保持裸字。
- 词头只有单个汉字时才走"生字"逻辑（组词朗读、拼音提示）；多个汉字的行必须写成裸词语，不能带拼音/组词列。
- 词头里出现 `/`、`...`、`…`、前导 `(`、结尾数字（`content1`）不会被拒绝，但朗读效果存疑——新增词条请避免这些写法。

## 4. 校验

```bash
python3 scripts/check-assets.py            # 全量校验（CI 同步执行）
python3 scripts/check-assets.py --verbose  # 打印全部 warning
python3 scripts/check-assets.py --strict   # warning 也当失败
```

- **error**（退出码 1）：BOM、CRLF、空行、列数不是 1/3、空词头、同表内重复词头、生字行拼音格式非法、组词不含本字、多字中文行带列、生成资产（`ecdict-meta.json` / `hanzi-meta.json` / `compounds.json`）缺失或结构损坏。
- **warning**：词头带 `* # ^` 等记号、`/` 或省略号式词头、前导括号、结尾数字。历史来源原样带进来的这一类有几十条，**不要求为它们改动数据**；新提交别再增加。
- 生成资产由脚本产出，不要手改：`scripts/build-ecdict-meta.py`（离线英文词典）、`scripts/build-hanzi-meta.py`（裸汉字读音/组词）、`scripts/generate-compounds.py`（组词候选池）。
- 外部来源（粘贴 / OCR / 表格导出）先用第 8 节的 `scripts/import-wordlist.py` 规范化，再手工核对报告。

## 5. 新增一份词表

1. 新建 `app/src/main/assets/<分类>/<词表名>.txt`，按第 3 节写行。
2. `python3 scripts/check-assets.py` — 0 errors。
3. 若分类名或词表名引入了新的汉字，把该字补进 `domain/LabelOrder.kt` 的 `HANZI` 表（拼音 + 笔画数），并同步 `app/src/test/resources/library-label-order.json`；否则该字会掉进拉丁比较分支、排序错乱。
4. `./gradlew :app:testDebugUnitTest` — `LabelOrderTest` 会用手写顺序与比较器输出对拍，顺序写错就红。
5. 跑一次 `./gradlew :app:assembleDebug` 确认打包无误；真机上从「更多 → 词库」进新分类走查（列表能打开、能预览、能起听写）。

## 6. 授权与来源

- 现有词库来自 [alice](https://github.com/vvenv/alice)（MIT）与项目内人工录入；派生资产来自 ECDICT（MIT）与《现代汉语常用词表（草案）》。
- 可以提交：**从合法持有的教材整理出的字词数据**（识字表/写字表/词语表的字词本身是课程事实，不是教材的行文）。
- 不要提交：教材扫描件、课文原文、音频、以及任何整段照抄的商业出版物内容。
- 提交 PR 时在描述里写明来源（哪一版教材/哪一份官方字表）与整理方式，方便复核。
- 发现错行（错字、错拼音、错组词）请直接开 issue，附分类、词表名、行号与截图——词库错误优先于新功能修复。GitHub 上选「词库问题」issue 表单即可，字段与本文第 3 节对应。

## 7. 已收录的公共语料：课标字表

`义务教育语文课程标准/` 下的三份字表来自《义务教育语文课程标准（2022年版）》（教育部教材〔2022〕2号）附录 4 / 附录 5：

| 文件 | 内容 | 字数 |
|---|---|---|
| `基本字表 300.txt` | 附录4 识字、写字教学基本字表（按笔画排列） | 300 |
| `常用字表1 2500.txt` | 附录5 义务教育语文课程常用字表 表一（按音序排列） | 2500 |
| `常用字表2 1000.txt` | 附录5 义务教育语文课程常用字表 表二（按音序排列） | 1000 |

**来源与校验**（2026-09-10 整理）：

- 原文：教育部官网 PDF（[通知页](http://www.moe.gov.cn/srcsite/A26/s8001/202204/t20220420_619921.html)，`W020220420582344386456.pdf`）。该 PDF 是**影印件**，无可提取文本层，只能用 OCR 辅助核对。
- 文字转录取自 [`zispace/hanzi-chars`](https://github.com/zispace/hanzi-chars) 的 `data-charlist/《义务教育语文课程》（2022年版）*.txt`（逐行一字，附笔画/音序分节与部首变体注记）；本仓库的 `基本字表 300.txt` 去掉了原转录里附着在字后的部首变体括注（`人（亻）` → `人`），其余三份逐字一致。
- 交叉校验（**字集**）：表一 ∪ 表二 = 3500 字，与 [`shengdoushi/common-standard-chinese-characters-table`](https://github.com/shengdoushi/common-standard-chinese-characters-table) 的 `level-1.txt`（另一份独立转录的《通用规范汉字表》一级字）**逐字完全一致**；课标原文亦声明本字表等同《通用规范汉字表》一级字。分节统计与公开解读一致（1 画仅「一」，13 画仅「跳」，13 个部首变体字）。
- 交叉校验（**顺序**）：`scripts/verify-kebiao-scan.py` 逐页 OCR 影印件，按**印刷序号**与本源逐格比对（`python3 scripts/verify-kebiao-scan.py`，需先把 PDF 放到 `.cache/yuwen-kebiao-2022.pdf`）。实测：表一 2308 格中 83% 逐格吻合、表二 855 格中 67%，其余是 OCR 误读（比→止、皖→院 这类形近字），**无位置漂移**——表一出现连续 **45 格**完全吻合（漏字/多字会让其后所有序号整体错位，不可能出现这种长连击），且三个边界全部命中：表一 #1 = 阿、#2500 = 做、表二 #1000 = 佐。
- 词表边界：表一 #1 阿 … #2500 做、表二 #1 蔼 … #1000 佐，两表各按音序排列，页边界与序号游程对齐。
- 已知差异：源文件的说明写「全部300字都在常用字表一内」，实测 **「禾」在表二**（第 270 字），本仓库按实际数据收录（`DataFixtureTest` 断言的是 `基本字表 ⊆ 常用字表`）。
- 授权：字表本身是课程事实（课程标准附录），非教材行文；转录来源为公开仓库。若将来收到官方勘误，按第 5 节流程修正并在此记录。

## 8. 导入一份外部词表

粘贴、OCR、表格导出得到的原始文本先过 `scripts/import-wordlist.py`：

```bash
python3 scripts/import-wordlist.py --lang zh --category 语文 --label "二下 词语表" raw.txt
```

它只做**无歧义的格式修复**（BOM、CRLF、全角字符、行首序号、丢失的 `|` 分隔符——仅当形状可判定，如 `月　yuè　月亮`），随后按第 3 节校验；**不排序、不去重、不翻译词性、不生成拼音或组词**。文件顺序就是听写顺序，列内容就是朗读内容。默认拒绝覆盖已存在的词表（词表名是存储键）。

`--dry-run` 先看结果再落盘；写盘后仍需 `python3 scripts/check-assets.py` 与 `./gradlew :app:testDebugUnitTest`。
